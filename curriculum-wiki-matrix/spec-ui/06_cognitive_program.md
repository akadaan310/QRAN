# Cognitive Program — From Passive Reading to Active Structural Verification

The interface is a training instrument. Each feature exists to break one
passive habit and install its replacement. The transformation is the product;
the page is the gym.

## Habit-disruption map

| Passive habit | Disrupted by | Replacement habit |
|---|---|---|
| Vertical scroll as progress | F15 Echo-Trajectory (orbit mode) | Navigation as relation: ask what is connected, not where you are |
| Reading words in fixed order | F16 Path-Trace Lock (forced reversal) | Verification by retreat: sync is restored by re-walking, not pushing |
| Trusting the printed page | F17 Rasm Reveal (markers dissolve) | Substrate awareness: the skeleton needs nothing; layers are guests |
| One voice per line | F01/F14 Row splitting | Polyphonic attention: a line can be two chambers sharing a wall |
| All text as equal matter | F06 Passivity Lens | Participant/payload discernment: some records only lie flat |
| Summaries as free | F02 Collapse Lens + F11 Audit | Cost awareness: every key has a superposition price |
| Space as free | F20 Equilibrium Governor | Spatial economy: importance is a zero-sum claim on the page |
| Direction as given | F04 Shift Lens | Orientation as event: a thread can reverse mid-run |
| Coincidence as noise | F08 Convergence Lens | Footprint literacy: identical shapes are never accidents |
| Mergers as natural | F03 Dissolution Lens | License literacy: ask what permitted the merge |
| The margins as emptiness | F18 Operating Track | Instrument literacy: the frame is a tool |
| Between-lines as nothing | F19 Substrate Lens | Depth literacy: the gutter is a lens with three speeds |

## How the transformation compounds

Habits are not broken one at a time; they fall in sequences. The typical
compounding path:

1. **Orbit before order.** Once a reader has navigated radially (F15), linear
   scroll feels impoverished — the habit of "where am I" is permanently
   weakened.
2. **Retreat before advance.** After the first few path-trace locks (F16),
   readers begin to *feel* boundary layers approaching via the checkpoint
   glow. Anticipation replaces surprise.
3. **Skeleton before marks.** After the rasm reveal (F17), the vocalization
   layer is never again mistaken for the text itself. Every later reading
   carries substrate awareness underneath it.
4. **Audit before trust.** Once a reader has opened the invertibility audit
   (F11) on a collapsed key, summaries everywhere — inside and outside the
   system — start looking priced.

## What the system refuses to do

- It never auto-advances, auto-plays, or gamifies. No streaks, no scores, no
  leaderboards. The transformation is contemplative, not competitive.
- It never explains the text's *meaning*. It reveals structure; interpretation
  remains the reader's work. The interface is a verification instrument, not
  a commentary.
- It never hides its own mechanics. Every lens shows its cost strata, every
  merger shows its license, every collapse opens to audit. The system teaches
  suspicion of itself first.
