# Visual Typography System

Text behavior on the 15-line canvas. All typographic change is a function of
the five lane-state values (intensity, friction, axis, lens, depth) — nothing
is decorative, and the Arabic letterforms remain the primary visual material
at all times.

## Weight — structural intensity made visible

- Baseline weight is the classic page's even, calm black.
- As lane intensity rises (ledger anomaly density, friction), weight
  increases in continuous steps: the line literally gets heavier to look at.
- Ignited spans (F01), hottest friction spans (F10), and hub words (F15)
  carry the maximum weight on their lane.
- Passive material under the Passivity Lens (F06) drops below baseline to a
  quiet gray — weight is withdrawn, not just color.

## Spacing — room for voice

- Letter spacing expands on high viewpoint-axis-delta lines: a voice that
  traveled far is given room to land.
- Spacing contracts on passive and low-intensity lines: quiet material sits
  close together.
- Word spacing widens around seam fault lines (F01, F14) so the split reads
  as architecture, not crowding.

## Row heights — the zero-sum economy

- Row height follows intensity, governed by the equilibrium rule: total page
  height is constant, so a lane's expansion is visibly paid for by its
  neighbors' contraction.
- Expansion is eased, never snapped: lanes breathe over ~400ms so the reader
  perceives a claim being made, not a layout glitch.
- Minimum row height is sacred — no lane may contract below legibility, no
  matter how quiet. The governor redistributes; it never starves.

## Depth — friction as a physical plane

- Friction maps to z-lift: high-friction lanes rise toward the reader;
  quiet lanes settle back.
- Depth-of-field blur separates planes: when a lane is in focus (F14 shift,
  F15 hub, F16 lock), its neighbors soften proportionally to their depth
  distance.
- Shielded spans (F05) sink *below* the page plane — the only elements
  permitted negative depth.

## Multi-voice row splitting

When a lane forks (F01, F14), the split follows strict mechanics: the seam
fault line is drawn first (a hairline, full lane width), then the sub-rows
separate vertically within the lane's own height budget — the lane may claim
extra height from the governor, but the fork never invades neighboring
lanes. Each sub-row carries its own axis tint. Merging reverses the sequence
exactly.

## The rasm canvas

On Substrate Invariance Gesture (F17): the field goes clean gray; the dotless
skeleton stands in near-black with generous inter-line space; all rails dim
to minimal ticks. No weight variation, no tint, no depth — the skeleton is
shown as pure structure. Marker healing on release follows the reverse
sequence (dots, then vowel marks, then reading aids), each landing with a
fine ripple from the release point.

## Arabic-first law

The Arabic letterforms are never reduced, transliterated, or replaced in any
state of the system. All instrumentation, labels, and metrics live in the
margins in the interface language; the lines belong to the Arabic text
alone. Any future localization changes the rails, never the lanes.
