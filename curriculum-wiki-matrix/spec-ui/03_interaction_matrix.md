# Uniform Architectural Interface Matrix

Every feature, broken across the same four layers. Read rows for a single
feature's full behavior; read columns for the system's consistent grammar.

- **Physical Interaction Layer** — the exact gesture.
- **Visual Typography Layer** — how text weight, spacing, margins, and row
  heights behave as structural friction fluctuates.
- **Peripheral HUD Layer** — what the margins display.
- **Cognitive Transformation Goal** — which passive habit this disrupts and
  what replaces it.

## Column grammars (how to read down)

- **Physical:** every gesture is reversible; every mode has a named dismissal
  (tap seam, outward fling, spread, release). No dead ends.
- **Typography:** weight, spacing, row height, and depth are all functions of
  the five lane-state values (intensity, friction, axis, lens, depth).
  Nothing is decorative.
- **HUD:** content never enters the margins; instrumentation never covers the
  letterforms. The separation is law.
- **Cognitive:** each goal names a specific passive habit and its replacement.
  The full habit map is in `06_cognitive_program.md`.
