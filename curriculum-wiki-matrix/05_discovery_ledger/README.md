# Infinite Generative Discovery Ledger

Phase 3 of the Combined Theory Curriculum Wiki Matrix: a continuously generated,
never capped database of structural discoveries drawn from the three repository
architectures.

## Architectural mandate

The text array is treated throughout as an unmediated, mathematically rigid
typographic substrate interacting with dynamic viewpoint fields. Verse numbers,
historical proper names, localized chapter markers, and fixed thematic labels
are stripped away; what remains are universal abstract anomalies — structural
behaviors any substrate could exhibit.

## The three phases

- **Phase 1** — `phase1_anomaly_catalog/`: the exhaustive catalog of the nine
  structural anomaly properties, each detected in the repository assets,
  classified, and written as a universal anomaly entry.
- **Phase 2** — `phase2_pipeline/`: the endless generative computation
  pipeline. `PIPELINE.md` specifies the three-stage loop (Friction Vector →
  Invertibility Audit → Sovereign Notion Rows); `engine/ledger_engine.py`
  executes it over the full corpus substrate with no row cap; `runs/` holds
  every pass.
- **Phase 3** — `phase3_contract/ENFORCEMENT_CONTRACT.md`: the execution
  contract — continuity, three-sentence Runway discipline, mandatory friction
  tables, abstract-language enforcement, dependency honesty, and the
  defined-vs-executed boundary.

## Reading order

1. This file (mandate).
2. `phase1_anomaly_catalog/INDEX.md` — the nine profiles.
3. `phase2_pipeline/PIPELINE.md` — how rows are computed.
4. `LEDGER.md` — the live database index and query recipes.
5. `phase3_contract/ENFORCEMENT_CONTRACT.md` — the binding rules.
6. `wiki/curriculum-wiki.html` — the readable curriculum wiki, one study page per
   anomaly area (rebuild with `wiki/build_wiki.py` after any new run).

## Relation to the matrix

The ledger extends the wiki matrix (sections `00`–`04`) without altering it.
It reuses the matrix's structural contract — `[Cross_Plane_Layer]`,
`[Core_Pillar]`, `[Unified_Dependency]`, and the `[Runway]` / `[Excavator]` /
`[Collider]` tiers — and the Unified Nomenclature. R3 (ARABIC_TIMELESS) serves
as the invariant pole: its rules appear in every row's friction table, and its
metrics are ingested, but its layers are not scored as sequences.
